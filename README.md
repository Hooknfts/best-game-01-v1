Prism Drift is a neon arcade colour-matching game: fly a ship through a starfield, absorb orbs that match your ship's colour, dodge grey rocks, and chain matches into combos up to x8. Switch colours with Space or click, steer with arrows, WASD, or mouse.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 to play.
